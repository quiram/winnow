# Task tracking

Work on winnow is tracked as **GitHub Issues on [quiram/winnow](https://github.com/quiram/winnow/issues)**, reached with the `gh` CLI.

## Ticket conventions

None recorded yet, so `create-tasks`' own defaults apply: lead with the business goal, dedupe against existing issues, one goal per ticket, and keep tickets independent where possible, using GitHub's native dependency links where a dependency is unavoidable.
